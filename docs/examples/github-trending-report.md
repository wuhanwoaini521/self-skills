# 示例：github-trending-report

这个示例演示如何抓取 GitHub Trending，并生成带中英说明和 Mermaid 的报告。

重点看：

- `skills/github-trending-report/SKILL.md`
- `skills/github-trending-report/agents/openai.yaml`
- `skills/github-trending-report/scripts/generate_report.py`

适合学习：

- 如何把抓取逻辑封装成 skill
- 如何设计输出产物
- 如何在文档里加入结构化 Mermaid 示意
