# 学习入口

这个仓库按“先理解结构，再看示例，最后自己动手”的顺序组织。

推荐阅读顺序：

1. `getting-started/create-first-skill.md`
2. `concepts/repository-skill-layout.md`
3. `examples/crawl-docs-to-markdown.md`
4. `examples/github-trending-report.md`

配套目录：

- `skills/`：可直接复制和运行的 skill
- `templates/skill-starter/`：最小模板
- `tools/validate_skills.py`：检查 `skills/` 下 skill 结构是否合法
